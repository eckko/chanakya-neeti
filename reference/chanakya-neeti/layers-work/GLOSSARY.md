- mitra = friend (मित्र)
- bāndhava = kinsman (बन्धु)
- bhṛtya = servant (सेवक)
- dhana = wealth (धन); lakṣmī = fortune (लक्ष्मी)
- āpad / āpatti = adversity (आपत्ति); vyasana = calamity (विपत्ति)
- paṇḍita = learned man (पण्डित); prājña = wise man (बुद्धिमान)
- śāstra = treatise (शास्त्र); rājanīti = royal policy (राजनीति)
- dākṣiṇya = courtesy (शिष्टता); lajjā = modesty (लज्जा)
- śrotriya = Veda-learned brahmin (वेदपाठी ब्राह्मण)
